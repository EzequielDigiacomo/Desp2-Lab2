======================================================================
GUÍA DE USO: ¿DÓNDE SE EJECUTA CADA FUNCIÓN DE LIBRARY.PHP?
======================================================================

Este documento detalla en qué archivos PHP del proyecto se manda a llamar
cada una de las funciones contenidas en la biblioteca "funciones/library.php".

----------------------------------------------------------------------
1. DatosLogin_Hash($vUsuario, $vClave, $vConexion)
----------------------------------------------------------------------
* Se usa en: login.php (Línea 12)
* Propósito: Validar el inicio de sesión comparando la contraseña plana con el hash guardado.

----------------------------------------------------------------------
2. Existe_Usuario($vUsuario, $vConexion)
----------------------------------------------------------------------
* Se usa en: registro.php (Línea 33)
* Propósito: Verificar que el nombre de usuario no exista antes de registrarlo.

----------------------------------------------------------------------
3. Insertar_Usuario_Hash($vConexion, $vNombre, $vApellido, $vUsuario, $vClave, $vRol)
----------------------------------------------------------------------
* Se usa en: registro.php (Línea 37)
* Propósito: Insertar un nuevo usuario con la contraseña encriptada.

----------------------------------------------------------------------
4. Listar_Paises($vConexion)
----------------------------------------------------------------------
* Se usa en:
  - listado_paises.php (Línea 14): Muestra la tabla de todos los países.
  - carga_empresa.php (Línea 9): Llena el desplegable del país.

----------------------------------------------------------------------
5. Listar_Roles($vConexion)
----------------------------------------------------------------------
* Se usa en: registro.php (Línea 10)
* Propósito: Llena el desplegable de selección de rol del formulario de registro.

----------------------------------------------------------------------
6. Listar_Usuarios($vConexion)
----------------------------------------------------------------------
* Se usa en: listado_usuarios.php (Línea 14)
* Propósito: Trae la lista de usuarios para mostrarla en la tabla.

----------------------------------------------------------------------
7. Listar_Empresas($vConexion)
----------------------------------------------------------------------
* Se usa en:
  - listado_empresas.php (Línea 3): Muestra la tabla de todas las empresas.
  - carga_proyecto.php (Línea 4): Llena el desplegable de cliente para un nuevo proyecto.

----------------------------------------------------------------------
8. Listar_Proyectos($vConexion)
----------------------------------------------------------------------
* Se usa en:
  - listado_proyectos.php (Línea 3): Muestra la tabla de todos los proyectos.
  - editar_proyecto.php (Línea 7): Obtiene el proyecto a modificar.

----------------------------------------------------------------------
9. Listar_Lideres($vConexion)
----------------------------------------------------------------------
* Se usa en: carga_proyecto.php (Línea 5)
* Propósito: Llena el desplegable de líderes de proyecto.

----------------------------------------------------------------------
10. Insertar_Empresa($vConexion, $vDenominacion, $vPais, $vObservaciones, $vUsuarioCarga)
----------------------------------------------------------------------
* Se usa en: carga_empresa.php (Línea 25)
* Propósito: Guardar la nueva empresa ingresada por formulario.

----------------------------------------------------------------------
11. Insertar_Proyecto(...)
----------------------------------------------------------------------
* Se usa en: carga_proyecto.php (Línea 26)
* Propósito: Guardar el nuevo proyecto en estado inicial "Análisis Iniciado".

----------------------------------------------------------------------
12. Cancelar_Proyecto($vConexion, $idProyecto)
----------------------------------------------------------------------
* Se usa en: cancelar_proyecto.php (Línea 10)
* Propósito: Cancelar un proyecto cambiando su estado a ID 4.

----------------------------------------------------------------------
13. Borrar_Usuario_Logico($vConexion, $idUsuario)
----------------------------------------------------------------------
* Se usa en: borrar_usuario.php (Línea 10)
* Propósito: Borrado lógico de un usuario (Eliminado = 1, Activo = 0).

----------------------------------------------------------------------
14. Borrar_Empresa_Logico($vConexion, $idEmpresa)
----------------------------------------------------------------------
* Se usa en: borrar_empresa.php (Línea 10)
* Propósito: Borrado lógico de una empresa (Eliminado = 1).

----------------------------------------------------------------------
15. Borrar_Pais_Logico($vConexion, $idPais)
----------------------------------------------------------------------
* Se usa en: borrar_pais.php (Línea 10)
* Propósito: Borrado lógico de un país (Eliminado = 1).
