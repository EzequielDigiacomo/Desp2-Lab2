======================================================================
ESTRUCTURA DE LA BASE DE DATOS: consultora
======================================================================

----------------------------------------------------------------------
1. TABLAS MAESTRAS (Sin Dependencias)
----------------------------------------------------------------------

A) Tabla: roles
   - Propósito: Almacena los distintos niveles/roles de usuario del sistema.
   - Columnas:
     * Id (INT, PK, AUTO_INCREMENT): Identificador único del rol.
     * Denominacion (VARCHAR(50)): Nombre del rol.
   - Datos por defecto:
     * 1 -> Administrador
     * 2 -> Lider
     * 3 -> Analista Funcional
     * 4 -> Programador/a

B) Tabla: estados
   - Propósito: Almacena los posibles estados de un proyecto.
   - Columnas:
     * Id (INT, PK, AUTO_INCREMENT): Identificador único del estado.
     * Denominacion (VARCHAR(50)): Nombre del estado.
   - Datos por defecto:
     * 1 -> Analisis Iniciado
     * 2 -> En Desarrollo
     * 3 -> Terminado
     * 4 -> Cancelado

C) Tabla: paises
   - Propósito: Almacena los países en los que opera la consultora.
   - Columnas:
     * Id (INT, PK, AUTO_INCREMENT): Identificador único del país.
     * Denominacion (VARCHAR(50)): Nombre del país.
   - Datos por defecto:
     * 1 -> Argentina
     * 2 -> Uruguay
     * 3 -> Chile
     * 4 -> Brasil

----------------------------------------------------------------------
2. TABLAS CON RELACIONES (Con Dependencias)
----------------------------------------------------------------------

D) Tabla: usuarios
   - Propósito: Contiene la información de los usuarios registrados.
   - Columnas:
     * IdUsuario (INT, PK, AUTO_INCREMENT): Identificador único del usuario.
     * Usuario (VARCHAR(50), UNIQUE): Nombre de usuario/login.
     * Clave (VARCHAR(255)): Hash de la contraseña (bcrypt).
     * Nombre (VARCHAR(50)): Nombre del usuario.
     * Apellido (VARCHAR(50)): Apellido del usuario.
     * IdRol (INT, FK): Rol del usuario (relacionado con roles.Id).
     * Imagen (VARCHAR(100)): Nombre de archivo de la foto del usuario.
     * Activo (TINYINT, Default 1): Estado de la cuenta (1=Activo, 0=Inactivo).
     * Eliminado (TINYINT, Default 0): Bandera de borrado lógico (1=Eliminado, 0=No).
   - Relaciones:
     * FK: IdRol -> roles.Id (Un usuario tiene un rol asignado).

E) Tabla: empresas
   - Propósito: Clientes o empresas para las cuales la consultora hace proyectos.
   - Columnas:
     * Id (INT, PK, AUTO_INCREMENT): Identificador único de la empresa.
     * Denominacion (VARCHAR(100)): Nombre de la empresa.
     * IdPais (INT, FK): País de origen de la empresa (relacionado con paises.Id).
     * Observaciones (TEXT, NULL): Detalles adicionales.
     * FechaCarga (DATETIME): Fecha y hora del registro.
     * UsuarioCarga (VARCHAR(50)): Nombre del usuario que cargó el registro.
     * Eliminado (TINYINT, Default 0): Bandera de borrado lógico.
   - Relaciones:
     * FK: IdPais -> paises.Id (Una empresa pertenece a un país).

F) Tabla: proyectos
   - Propósito: Proyectos que desarrolla la consultora para las empresas.
   - Columnas:
     * Id (INT, PK, AUTO_INCREMENT): Identificador único del proyecto.
     * Denominacion (VARCHAR(100)): Nombre del proyecto.
     * IdEmpresa (INT, FK): Empresa cliente (relacionado con empresas.Id).
     * IdLider (INT, FK): Usuario líder asignado (relacionado con usuarios.IdUsuario).
     * Observaciones (TEXT, NULL): Detalles adicionales.
     * Prioridad (TINYINT, Default 0): Indicador si es urgente (1=Prioridad, 0=Normal).
     * IdEstado (INT, FK, Default 1): Estado actual (relacionado con estados.Id).
     * FechaCarga (DATETIME): Fecha y hora de creación.
     * UsuarioCarga (VARCHAR(50)): Nombre del usuario que cargó el proyecto.
     * Eliminado (TINYINT, Default 0): Bandera de borrado lógico.
   - Relaciones:
     * FK: IdEmpresa -> empresas.Id (El proyecto pertenece a una empresa).
     * FK: IdLider -> usuarios.IdUsuario (El proyecto tiene asignado un líder).
     * FK: IdEstado -> estados.Id (El proyecto tiene un estado de avance).

----------------------------------------------------------------------
3. DIAGRAMA CONCEPTUAL DE RELACIONES
----------------------------------------------------------------------

      [roles] 1 <------- N [usuarios] 1 <------- N [proyectos]
                                                        | N
     [paises] 1 <------- N [empresas] 1 <------- 1      |
                                                        v
                                                    [estados] (1 <------- N proyectos)

EXPLICACIÓN DE FUNCIONES DE LA BIBLIOTECA: funciones/library.php
======================================================================

A continuación se detalla el funcionamiento, parámetros y propósito de cada función contenida en library.php:

----------------------------------------------------------------------
1. DatosLogin_Hash($vUsuario, $vClave, $vConexion)
----------------------------------------------------------------------
* Propósito: Realiza la autenticación (inicio de sesión) de un usuario en el sistema.
* Parámetros:
  - $vUsuario (string): Nombre de usuario ingresado en el formulario.
  - $vClave (string): Contraseña ingresada en texto plano.
  - $vConexion (mysqli): Objeto de conexión activa a la base de datos.
* Funcionamiento detallado:
  1. Inicializa un array vacío llamado `$Usuario`.
  2. Prepara una consulta SQL que busca en la tabla `usuarios` al registro donde la columna `Usuario` coincida con el valor de `$vUsuario` y que no esté marcado como eliminado (`Eliminado = 0`). Además, realiza un `JOIN` con la tabla `roles` para traer la denominación del rol.
  3. Ejecuta la consulta SQL y, si obtiene un resultado, extrae la fila correspondiente.
  4. Utiliza la función nativa de PHP `password_verify($vClave, $data['Clave'])` para comparar la contraseña ingresada con el hash de contraseña encriptado con bcrypt que está almacenado en la base de datos.
  5. Si coinciden, almacena la información relevante del usuario en el array `$Usuario` (ID, Nombre, Apellido, ID de Rol, Nombre de Rol, imagen y si está activo). Si el usuario no tiene una imagen configurada, le asigna por defecto 'login.png'.
  6. Retorna el array `$Usuario` (si las credenciales son incorrectas o el usuario no existe, el array devuelto queda vacío).

----------------------------------------------------------------------
2. Listar_Paises($vConexion)
----------------------------------------------------------------------
* Propósito: Obtener un listado de todos los países de la base de datos que se encuentran activos.
* Parámetros:
  - $vConexion (mysqli): Objeto de conexión a la base de datos.
* Funcionamiento detallado:
  1. Inicializa un array vacío llamado `$Listado`.
  2. Ejecuta una consulta SQL para seleccionar todos los países de la tabla `paises` que tengan `Eliminado = 0`, ordenándolos alfabéticamente por su denominación (`ORDER BY Denominacion`).
  3. Mediante un bucle `while`, recorre cada fila devuelta por la base de datos y añade al array `$Listado` un sub-array con las llaves 'ID' y 'NOMBRE'.
  4. Retorna el array `$Listado` con todos los países.

----------------------------------------------------------------------
3. Listar_Roles($vConexion)
----------------------------------------------------------------------
* Propósito: Obtener un listado de todos los roles existentes en el sistema.
* Parámetros:
  - $vConexion (mysqli): Objeto de conexión a la base de datos.
* Funcionamiento detallado:
  1. Inicializa un array vacío llamado `$Listado`.
  2. Ejecuta una consulta SQL en la tabla `roles` ordenada alfabéticamente por su denominación.
  3. Itera sobre los resultados mediante un bucle `while`, guardando en `$Listado` el 'ID' y el 'NOMBRE' de cada rol.
  4. Retorna el listado resultante.

----------------------------------------------------------------------
4. Listar_Usuarios($vConexion)
----------------------------------------------------------------------
* Propósito: Obtener un listado completo de los usuarios registrados que no han sido eliminados.
* Parámetros:
  - $vConexion (mysqli): Objeto de conexión a la base de datos.
* Funcionamiento detallado:
  1. Inicializa un array vacío `$Listado`.
  2. Ejecuta una consulta que realiza un `JOIN` entre las tablas `usuarios` (U) y `roles` (R) para obtener los datos del usuario y el nombre de su rol. Filtra únicamente a los usuarios activos (`U.Eliminado = 0`) y los ordena por su Apellido y luego por su Nombre.
  3. Itera sobre los resultados guardando en `$Listado` los datos del usuario: ID, Nombre, Apellido, Nombre de usuario, Rol e Imagen de perfil (si la imagen está vacía, se asigna por defecto 'login.png').
  4. Retorna el array con el listado de usuarios.

----------------------------------------------------------------------
5. Listar_Empresas($vConexion)
----------------------------------------------------------------------
* Propósito: Obtener el listado de todas las empresas clientes activas (no eliminadas lógicamente).
* Parámetros:
  - $vConexion (mysqli): Objeto de conexión a la base de datos.
* Funcionamiento detallado:
  1. Inicializa un array vacío `$Listado`.
  2. Ejecuta una consulta SQL en la tabla `empresas` (E) haciendo un `JOIN` con la tabla `paises` (P) para conocer el país de origen de la empresa, y un `LEFT JOIN` con `usuarios` (U) para obtener información del usuario que cargó la empresa (`UsuarioCarga`).
  3. Filtra excluyendo los registros eliminados (`E.Eliminado = 0`) y los ordena alfabéticamente.
  4. Itera sobre el resultado cargando en `$Listado`: ID, Denominación, Fecha de carga, Usuario de carga, País y además genera el nombre completo formateado del creador ("Apellido Nombre" o el nombre de usuario si no está en la tabla de usuarios) y su imagen.
  5. Retorna la colección de empresas.

----------------------------------------------------------------------
6. Listar_Proyectos($vConexion)
----------------------------------------------------------------------
* Propósito: Listar todos los proyectos activos en la base de datos con su información asociada (empresa, líder, estado y país).
* Parámetros:
  - $vConexion (mysqli): Objeto de conexión a la base de datos.
* Funcionamiento detallado:
  1. Inicializa un array vacío `$Listado`.
  2. Ejecuta una consulta SQL compleja realizando múltiples `JOIN`:
     - Une `proyectos` con `empresas` para obtener el nombre del cliente.
     - Une `empresas` con `paises` para obtener el país del cliente.
     - Une `proyectos` con `usuarios` (líder del proyecto) para obtener nombre, apellido e imagen de perfil del líder asignado.
     - Une `proyectos` con `estados` para saber el estado de avance del proyecto.
  3. Filtra para traer solo los proyectos que no han sido borrados lógicamente (`PR.Eliminado = 0`) y los ordena por su fecha de carga de forma ascendente (los más antiguos primero).
  4. Recorre los resultados guardando en `$Listado` los datos estructurados: ID del proyecto, Título/Denominación, Fecha de carga, Prioridad, nombre de la Empresa cliente, País, Nombre completo del Líder, Imagen del Líder, ID del Estado y Nombre del Estado.
  5. Retorna la lista de proyectos.

----------------------------------------------------------------------
7. Listar_Lideres($vConexion)
----------------------------------------------------------------------
* Propósito: Obtener únicamente los usuarios que pueden ser asignados como líderes de proyecto.
* Parámetros:
  - $vConexion (mysqli): Objeto de conexión a la base de datos.
* Funcionamiento detallado:
  1. Inicializa un array vacío `$Listado`.
  2. Realiza un `SELECT` en la tabla `usuarios` filtrando por aquellos que tengan asignado el rol con ID 2 (Líder) y que no estén eliminados. Los ordena por Apellido y Nombre.
  3. Recorre los resultados guardando en `$Listado` el ID del usuario y una cadena formateada como "Apellido, Nombre" en el índice 'NOMBRE_COMPLETO' (ideal para rellenar campos desplegables de selección HTML).
  4. Retorna el array.

  2. Retorna `true` si la inserción se realiza con éxito, y `false` en caso de que ocurra algún error.

======================================================================
CONCEPTOS CLAVE DE PHP Y FUNCIONES COMUNES
======================================================================

1. session_start()
----------------------------------------------------------------------
* Propósito: Activar o reanudar la memoria del servidor para la sesión del usuario en el navegador actual.
* Explicación simple: Le dice al servidor que recuerde al usuario mientras navega entre las diferentes páginas del sitio. Debe colocarse al inicio del archivo antes de cualquier salida HTML.

2. $_SESSION
----------------------------------------------------------------------
* Propósito: Variable súper-global en forma de array utilizada para almacenar información del usuario a lo largo de su visita.
* Explicación simple: Una caja de memoria en la que guardamos datos que no queremos que se pierdan al cambiar de página (por ejemplo, el nombre del usuario logueado, su rol o mensajes de alerta temporales).

3. $_GET
----------------------------------------------------------------------
* Propósito: Variable súper-global que almacena los parámetros enviados mediante la URL (después del signo "?").
* Explicación simple: Sirve para recibir datos que viajan en la barra de direcciones. Si la dirección es "editar_proyecto.php?id=5", podemos obtener ese número usando $_GET['id'].

4. header('Location: login.php') y header('Location: index.php')
----------------------------------------------------------------------
* Propósito: Enviar una cabecera HTTP de redirección al navegador.
* Explicación simple: Desvía automáticamente al usuario a otra pantalla del sistema (por ejemplo, al formulario de login o al panel de inicio).

5. mysqli_query($vConexion, $SQL)
----------------------------------------------------------------------
* Propósito: Ejecutar una consulta o comando SQL en la base de datos MySQL activa.
* Explicación simple: Toma la conexión abierta y la consulta SQL que escribimos en PHP, y las envía a la base de datos para que realice la operación (seleccionar, insertar, actualizar o eliminar).

6. mysqli_fetch_array($Resultado)
----------------------------------------------------------------------
* Propósito: Convertir los resultados crudos obtenidos de una consulta SELECT en un formato (array) accesible por PHP.
* Explicación simple: MySQL nos devuelve los datos agrupados en un paquete cerrado. Esta función abre ese paquete fila por fila y lo traduce a una lista de claves y valores (ej. $fila['Nombre']) para que podamos usarlos en el código.

7. Script de Cerrar Sesión (CerrarSesion.php)
----------------------------------------------------------------------
* Ejemplo práctico:
  <?php
  session_start(); // 1. Activa y recupera la sesión actual del usuario.
  session_destroy(); // 2. Borra permanentemente toda la información de la sesión.
  header('Location: login.php'); // 3. Redirecciona al usuario a la pantalla de login.
  exit(); // 4. Detiene inmediatamente la ejecución de cualquier código restante por seguridad.
  ?>

8. trim($_POST['...'])
----------------------------------------------------------------------
* Propósito: Limpiar espacios en blanco de los datos de entrada del formulario.
* Funcionamiento:
  - trim(): Quita espacios en blanco innecesarios al inicio y al final del texto ingresado por el usuario (por ejemplo, si presiona la barra espaciadora por accidente al principio o final).

9. intval($_POST['...'])
----------------------------------------------------------------------
* Propósito: Convertir o forzar una variable al tipo número entero (Integer).
* Explicación simple: Asegura que el dato sea un número válido y limpio para operar en la base de datos. Si el usuario ingresa texto malicioso o por error, se convertirá en un valor numérico seguro (por ejemplo, "15" pasa a ser 15, y "hola" pasa a ser 0).

10. isset($_POST['...'])
----------------------------------------------------------------------
* Propósito: Verificar si una variable o elemento del formulario existe y no es nulo.
* Explicación simple: Sirve para comprobar si el usuario realmente envió el formulario (por ejemplo, haciendo clic en el botón de registrar) antes de que PHP intente leer los datos, previniendo errores de variable indefinida.

11. strlen($vVariable)
----------------------------------------------------------------------
* Propósito: Obtener la longitud de una cadena de texto (String).
* Explicación simple: Cuenta la cantidad de letras o caracteres que tiene un texto. Es muy útil para validar que un nombre de usuario o contraseña cumpla con un mínimo requerido (por ejemplo, al menos 3 caracteres).

12. date() y strtotime()
----------------------------------------------------------------------
* Propósito: Mostrar las fechas de la base de datos en un formato amigable (ej: "Día/Mes/Año").
* Explicación simple:
  - En la base de datos la fecha se guarda como texto ordenado año-mes-día: "2026-06-07 18:28:41".
  - La función date() sirve para darle formato, pero requiere la fecha medida en segundos para poder procesarla.
  - strtotime() toma la fecha en texto de la base de datos y la convierte a un número de segundos (Unix timestamp).
  - Combinación: date('d/m/Y', strtotime($vFecha)) primero traduce la fecha a segundos con strtotime, y luego date la convierte a la estructura clásica "día/mes/año" (07/06/2026).

1. Autenticación de Usuario (DatosLogin_Hash)
----------------------------------------------------------------------
* Código SQL:
  SELECT U.IdUsuario, U.Nombre, U.Apellido, U.IdRol, U.Imagen, U.Clave, U.Activo, R.Denominacion as NombreRol 
  FROM usuarios U 
  JOIN roles R ON U.IdRol = R.Id 
  WHERE U.Usuario = '$vUsuario' AND U.Eliminado = 0

* Explicación breve: Busca en la tabla 'usuarios' (U) al usuario que intenta ingresar, trayendo además el nombre de su rol desde la tabla 'roles' (R) mediante un JOIN.

4. Listar Usuarios (Listar_Usuarios)
----------------------------------------------------------------------
* Código SQL:
  SELECT U.IdUsuario, U.Nombre, U.Apellido, U.Usuario, U.Imagen, R.Denominacion as Rol 
  FROM usuarios U 
  JOIN roles R ON U.IdRol = R.Id

  ORDER BY U.Apellido, U.Nombre

5. Listar Empresas (Listar_Empresas)
----------------------------------------------------------------------
* Código SQL:
  SELECT E.Id, E.Denominacion, E.FechaCarga, E.UsuarioCarga, P.Denominacion as Pais, U.Nombre, U.Apellido, U.Imagen 
  FROM empresas E 
  JOIN paises P ON E.IdPais = P.Id 
  JOIN usuarios U ON E.UsuarioCarga = U.Usuario 
  WHERE E.Eliminado = 0 
  ORDER BY E.Denominacion ASC

* Explicación breve: Obtiene las empresas activas (E), uniendo la tabla de 'paises' (P) para mostrar el nombre del país del cliente, y la tabla de 'usuarios' (U) mediante un JOIN clásico para mostrar el nombre y apellido reales del creador del registro.

6. Listar Proyectos (Listar_Proyectos)
----------------------------------------------------------------------
* Código SQL:
  SELECT PR.Id, PR.Denominacion, PR.FechaCarga, PR.Prioridad, E.Denominacion as Empresa, P.Denominacion as Pais, U.Nombre, U.Apellido, U.Imagen, ES.Id as IdEstado, ES.Denominacion as Estado 
  FROM proyectos PR 
  JOIN empresas E ON PR.IdEmpresa = E.Id 
  JOIN paises P ON E.IdPais = P.Id 
  JOIN usuarios U ON PR.IdLider = U.IdUsuario 
  JOIN estados ES ON PR.IdEstado = ES.Id 
  WHERE PR.Eliminado = 0 
  ORDER BY PR.FechaCarga ASC

* Explicación breve: Cruza la tabla 'proyectos' (PR) con 'empresas' (E), 'paises' (P), 'usuarios' (U) y 'estados' (ES) usando INNER JOINs para construir un listado con los nombres reales de las empresas, países, líderes y estados correspondientes sin usar alias complejos para las columnas de usuarios.
